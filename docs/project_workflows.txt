1. Registration Flow (all user types)
Visitor → Choose role: Customer / Farmer / B2B
  → Enter mobile → OTP verify (Supabase Auth)
  → Optional Gmail sign-in
  → Role-specific details:
      Customer: name, address (Mapbox pin), pincode
      Farmer:   name, farm location pin, Aadhaar/KYC,
                bank account (for payouts), crops grown, photo
      B2B:      business name, GSTIN, address, license upload
  → Farmer & B2B go to "Pending" → Admin verifies KYC → Approved
  → Customer is active immediately
2. Customer Buying Flow
Login → Home (welcome banner, hovering images, offers)
  → Location auto-detect or pin on Mapbox
  → Set radius (5/10/25 km)
  → PostGIS query returns farmers + products in radius
  → Product page: price, unit (kg/g/unit/ton/quintal),
    farmer profile, distance, ratings
  → Add to cart → Checkout
  → Pay via Razorpay (UPI/card/COD option)
  → Order confirmed → live status tracking
  → After delivery: rate farmer
  → Dashboard shows "You saved ₹X vs market rate"
3. Farmer Selling Flow
Login → Farmer dashboard
  → Add product: name, photo, price, unit, stock, category
  → Product goes live in their radius
  → New order alert (FCM + WhatsApp)
  → Accept / Reject order
  → Pack → mark ready → delivery
  → Razorpay Route auto-credits farmer's bank
    (order amount minus platform commission)
  → Dashboard: "Earned ₹X via Aswamithra",
    orders history, payout statements, stock alerts
4. B2B Flow
Login → B2B catalog (bulk pricing: quintal/ton tiers)
  → Request quote or order directly
  → GST invoice auto-generated
  → Payment: full / partial advance
  → Delivery scheduling for bulk
  → Dashboard: purchase history, GST reports, credit ledger
5. Commission Engine (Admin-controlled)
commission_slabs table:
  min_amount | max_amount | rate%
  0          | 10,000     | 4.5
  10,001     | ∞          | 4.0

On payment → backend reads slab → Razorpay Route splits:
  Farmer share → farmer bank account
  Commission  → your platform account
Admin can edit slabs anytime from panel — no code change
6. Admin Panel Flow
Admin login (separate secure URL, role-based access)
  → Verify/approve farmers & B2B (KYC review)
  → Open shops location-wise, assign products
  → Adjust commission slabs
  → Manage banners, welcome notes, hover images
  → Billing system: invoices, settlement reports
  → India map view: active locations, farmer density
  → Analytics: sales, top products, savings/earnings totals
  → Manage social media links shown in footer
  → Handle refunds & disputes
7. Order Status Lifecycle
PLACED → FARMER_ACCEPTED → PACKED → OUT_FOR_DELIVERY
       → DELIVERED → (optional) RETURN/REFUND
Each step triggers FCM + WhatsApp notification to both sides
8. Core Database Tables
users (role: customer/farmer/b2b/admin) · farmer_profiles (KYC, bank, geo-point) · products (price, unit, stock) · orders + order_items · commission_slabs · payments + payouts · shops (admin-created, location-wise) · savings_ledger (customer saved ₹) · earnings_ledger (farmer earned ₹) · banners, social_links, reviews, notifications
9. Deployment on Your VPS
Docker containers:
  nginx (SSL) → next.js frontend → nestjs API
  → postgresql+postgis → redis → supabase (auth/storage)
Daily automatic DB backup → object storage
Later: same containers lift to Google Cloud, zero rewrite
Build order I recommend: Registration + OTP → Farmer product listing → Customer radius browsing → Cart + Razorpay → Commission engine → Dashboards (earned/saved) → Admin panel → B2B → mobile app.
